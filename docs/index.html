What soaim does

One job: tell you how often you cuss at your coding agents.

[#@!]

Counts your swears

Whole-word, case-insensitive matching over your own prompts. Every occurrence counts — a prompt with two swears counts two. The word list is configurable.

[%]

Per-app breakdown

Every statistic is split across five apps with fixed colors, so you can see whether Claude Code or Codex gets the worst of your temper.

[~/]

100% offline & read-only

It only reads your local prompt history. No network calls, no telemetry, and it never writes to any tool's files. Results cache in its own SQLite database.

Supported agents

Five sources. Three read by default; two best-effort until you point soaim at them.

[cc]

Claude Code

~/.claude/projects/**/*.jsonl
JSONL prompt log, read directly.

Implemented
[cx]

Codex CLI

~/.codex/history.jsonl + rollouts
JSONL history and session records.

Implemented
[oc]

opencode

~/.local/share/opencode/opencode.db
SQLite, opened strictly read-only.

Implemented
[cd]

Claude Desktop

~/Library/Application Support/Claude
Best-effort JSONL scan — run soaim discover to locate the store.

Best-effort
[ca]

Codex App

~/Library/Application Support/Codex
Best-effort JSONL scan — run soaim discover to locate the store.

Best-effort
[+]

Bring your own

Override any source path in config.toml or via --config. A missing tool simply contributes zero — the rest keep working.

Installation

Two ways to get started.

Homebrew (macOS)

Terminal 
$ brew tap maximgorbatyuk/tap
$ brew install soaim

# Ingest prompts, then open the dashboard
$ soaim

Build from source (cross-platform)

Terminal 
# Requires a recent stable Rust toolchain (1.74+)
$ cargo build --release
$ ./target/release/soaim

macOS, Linux, and Windows. SQLite is compiled in — no system dependency.
